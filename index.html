모드 설명

START → 화면·표적 초기화 후 시간이 올라가고, 5발 명중 시 멈춥니다. 표적은 자동 리셋되지 않으니 START(다시 시작)나 RESET을 누르세요.

제한 시간이 끝나면 표적이 명중을 인식하지 않습니다. START를 누르면 초기화 후 타이머가 다시 시작됩니다.

시간이 끝나거나 5발을 다 맞추면 표적이 바로 리셋되고 다음 사수 차례가 자동으로 시작됩니다. 직전 사수 결과는 타이머 아래에 표시됩니다.
